# Reflection

The Programming Technique II course provided valuable knowledge and practical experience in object-oriented programming (OOP) using the C++ programming language. It established a strong foundation in applying object-oriented principles to design and develop structured and maintainable software systems.

Throughout the course, comprehensive understanding was developed in key OOP concepts such as encapsulation, inheritance, polymorphism, associations, and object manipulation. These concepts were reinforced through lectures, exercises, laboratory sessions, and project-based learning activities, ensuring both theoretical knowledge and practical application.

Hands-on programming tasks and the mini project significantly enhanced problem-solving, analytical thinking, and coding skills. The ability to design and implement medium-scale applications using object-oriented approaches was strengthened, improving understanding of modular and reusable software development practices.

In addition, teamwork and collaboration skills were enhanced through group project activities, discussions, and GitHub-based teamworking assessments. These experiences encouraged effective communication, version control practices, and collaborative problem-solving in a shared development environment.

Exposure to UML class diagrams, software design techniques, and advanced C++ features further increased understanding of structured software development practices in real programming environments. This highlighted the importance of proper design planning and implementation in producing efficient and scalable software systems.

Overall, the course successfully enhanced both theoretical understanding and practical competency in object-oriented programming and software development using C++, while strengthening confidence in applying these skills in academic and professional contexts.
