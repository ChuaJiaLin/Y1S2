# Reflection

The System Analysis and Design course provided valuable knowledge and practical experience in system development methodologies, project planning, system analysis, and system design processes used in real-world information systems development. It established a strong foundation for understanding how structured approaches contribute to the successful delivery of software and information systems.

Throughout the course, comprehensive understanding was developed in key areas such as project feasibility studies, project management, data flow diagrams (DFD), user interface design, system implementation, and object-oriented analysis and design. These concepts were reinforced through lectures, quizzes, laboratory exercises, and project-based learning activities, ensuring both theoretical knowledge and practical application.

The industry-based group project significantly enhanced practical skills in analysing real organizational problems, gathering system requirements, designing system models, and developing suitable system solutions using both structured and object-oriented approaches. This experience strengthened the ability to apply systematic analysis and design techniques in solving real-world challenges.

In addition, teamwork, communication, leadership, and problem-solving skills were improved through collaborative project development, presentations, peer assessments, and industry evaluation activities. These interactions encouraged active participation, effective coordination, and clear communication of technical ideas in professional settings.

Exposure to Agile tools, modelling techniques, UML diagrams, and real-world case studies further increased understanding of how systematic planning, requirement analysis, and design processes contribute to the development of reliable and efficient systems. This highlighted the importance of structured methodologies in ensuring project success and system quality.

Overall, the course successfully enhanced both theoretical understanding and practical competency in system analysis, system design, and project management within software development environments, while strengthening confidence in applying these skills in real-world contexts.
